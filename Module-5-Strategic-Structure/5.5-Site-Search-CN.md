# 5.5 选址策略 (Site Search)

## 1. 核心方向

不看市场挂牌的常规 maison（成本高），优先找**废弃/闲置资产**：
- 成本更低。
- 更容易拿到市镇支持走 changement d'usage（改变用途）。
- 理想目标：一栋有历史的 **atelier d'artiste**（艺术家工作室）——不只是省钱，也是给项目本身注入"有情怀"的叙事，跟 README 的季节感官愿景是同一条美学线。

买/租尚未决定，倾向买（apport + 融资），融资来源仍在讨论中（见第 6 节）。

## 2. 废弃资产的两条法定路径

法国市镇接手废弃房产主要走两种程序，两者都不会出现在 SeLoger / BureauxLocaux 这类地产门户，只能直接问市镇：

- **Bien sans maître（无主财产）**：业主身份不明、且超过法定年限未缴房产税。市镇发起调查 + 不动产权利公示程序后，可由市长签发命令并入市镇资产；市镇拒绝接手的话，财产归国家所有。
- **Abandon manifeste（明显弃置状态）**：业主身份已知，但房子有明显破败迹象（屋顶塌陷、植被入侵、安全隐患）。市镇可发起弃置认定程序，可能走向公用征收。

**行动项**：9/15 见 mairie 时直接问——市镇手上有没有正在走这两个程序的房产，是否可能协商用于微托项目（普惠型婴幼儿服务对市镇本身也是加分项，可作为谈判角度）。

### 具体线索：75 rue Alexandre Néreau, Palaiseau

- **一栋房子 + 一座 manoir（带塔楼的老宅），都处于闲置/废弃状态**，就在同一条街上。
- Rue Alexandre Néreau 是 Palaiseau 最古老的街道之一，meulière 石砌老房、老墙保留完好，市政资料称其"让人看到过去的 Palaiseau"，历史上还有本地协会为反对拓宽这条街而成立，就是为了保住这片老城区风貌。
- **房子（约75号）**：据一份来源，目前**属于市镇所有**。2023年有本地团体组织过抗议，专门点名指出 rue Alexandre Néreau 上有几栋被市镇收购后长期闲置、门窗被封的房子——跟这个说法吻合，但没有查到市镇官方文件明确写"75号归市镇"，需要当面向 mairie 核实。
- **Manoir**：更神秘，没查到最近的 permis de construire、没有修复项目、也没有列入历史建筑保护(monuments historiques)。不代表法律上"废弃"——也可能只是私人闲置资产，在等继承/出售/未来项目。
- **这是目前唯一一个带具体门牌号的候选地址**，9/15 见面可以直接拿这个地址问，比空泛地问"有没有废弃房子"精准得多。
- **补充线索**（网上核实，2026-08-26）：查到2023年本地居民 François Delfaud 发起的联署请愿（[来源](https://www.mypetition.org/petition/social/palaiseau-cedez-maisons-murees-rue-alexandre/224257)），确认 rue Alexandre Néreau 上**共有3栋市镇所有的封窗空置房**，就在 **Théâtre de la Passerelle 剧院旁边**——这个地标比门牌号更好找，实地走一趟应该能直接看到。请愿诉求是市镇把至少一栋让渡给应急住房机构（Emmaüs Habitat、SNL），说明市镇内部确实有把这类房子挪作公益用途的先例讨论，可以作为跟 mairie 谈判时的一个参照点。请愿本身没有点名其他街道的房子，这条线索到此挖完。

### 第二条历史街区线索：rue de Paris（原名 rue de Chartres）

据市镇官方历史资料（[ville-palaiseau.fr](https://www.ville-palaiseau.fr/attractive/ville-dequilibre/histoire)），Palaiseau 老城原本是沿着今天的 rue de Paris 展开的"村庄街"（village-rue）——菜园、洗衣坊、grès 门廊、12/14/18世纪老宅、以及 meulière 石砌房都在这条街上，跟 rue Alexandre Néreau 是同一时期的老城肌理。**目前还没查到这条街上有具体的空置/破败建筑**，纯粹是"同类型街区，值得实地走一趟看有没有封窗老宅"的线索，不是一个已确认的候选地址。

## 3. 实操工具

- **[Cartofriches (Cerema)](https://cartofriches.cerema.fr/cartofriches/)**——生态转型部委托 Cerema 建的全国性废弃场地开放数据地图，收录工业/商业/住宅类 friches。已收录 8000+ 场地，可按 Palaiseau/Essonne 范围直接筛。**这是目前最值得亲自去用的工具。**

## 4. Atelier d'artiste 线索

- **DRAC Île-de-France**：官方负责分配全区空置的 atelier / atelier-logement。2025 年全区申报空置 44 个，75% 由 DRAC 谈成。⚠️ 提醒：这个渠道设计初衷是给在职艺术家 work/live 用，直接申请拿来做商业微托可能不完全对口，但值得问——尤其如果里面有房子 DRAC 已经不再分配。
- **[Inventaire Général du Patrimoine Culturel — Ateliers d'artistes en Île-de-France](https://inventaire.iledefrance.fr/dossier/ateliers-d-artistes-en-ile-de-france/188709fc-e79e-4f42-be66-43b7ce6c7bd7)**——文化遗产普查档案，可能列出区域内具体的历史 atelier 建筑。**最有希望挖到"有历史有情怀"那种房子的地方，值得直接点进去查有没有 Palaiseau 或邻近市镇的条目。**
- [La Maison des Artistes 小广告](https://www.lamaisondesartistes.fr/site/les-petites-annonces-de-la-maison-des-artistes/les-annonces/185/ateliers-et-bureaux-offres/?results=90)——现有招租/转让的 atelier 信息。

## 5. Changement de destination（改变用途）关键卡点

- 微托通常归为 PLU 里的 **"équipements d'intérêt collectif et services publics (EICSP)"** 类别——能不能改用途，取决于该地块 PLU 是否允许这个 destination。**必须提前查该地块 PLU，不是随便一栋废弃房子都能批。**
- 视工程量大小，走 **déclaration préalable** 或 **permis de construire**。

## 6. 融资来源（已确认可用）

- **CAF 投资补贴**：每个托育名额 **7,400–17,000€**。以下情况补贴上浮：涉及大工程（gros œuvre）、走高环保标准（HQE）、项目落在托育覆盖率低于全国平均或财政能力弱的区域。**废弃建筑改造大概率能踩中"gros œuvre"这条加成。**
- **Fonds de modernisation des établissements**（CAF，2023–2027 共 242.6M€）——针对老旧托育设施的现代化改造，2026 年 appels à projets 已启动。
- 这两项资金，配合 issue #3（Detailed Financial Projections）和 #15（Draft Project Dossier）能直接写进 dossier。

## 8. 融资策略 — "零氪金"游戏规则

核心原则：**不用创始人自己的现金**，靠非稀释性公共资金 + 市镇公共利益合作解决"钱"和"房子"两件事。不是去银行贷款、不是拿硬件项目抵押房产——是把 Track A（科技）和 Track B（房子）分开走，用 Track A 产出的信誉/故事资本，去撬动 Track B 更好的条件。

### Track A — BLE 定位系统走"创新/科技"这条钱

**已定案**：以"一人公司"形式推进，利用创始人自己的全栈工程师背景，独立把 BLE + AI 做出来，作为撬动首付的杠杆。CAF 和其他正规政府补贴依然优先、更受欢迎（不走偏门），但这条 Track A 本身不是可选项，是已经决定要做的事——同时它也不只是工具，是创始人想真正拥有、按自己节奏推进的东西，不因为 crèche 那边的时间线（比如 9/15 mairie 会面）而被要求加速。

1. **[Bourse French Tech](https://www.bpifrance.fr/catalogue-offres/bourse-french-tech)**（Bpifrance）——上限 5万€，实际常批约3万€，覆盖最多70%费用，零股权、不用还。门槛匹配"硬件刚到手、早期摸索阶段"，现在就可以准备材料申请，是当前最匹配进度的第一步。
2. **Station F Founders Program**——equity-free，最长可待 18 个月。拿到这个身份本身是信誉筹码：跟 mairie/CAF 谈判时是很有分量的背书。
3. 硬件验证可行性之后，冲 **[i-Lab](https://www.bpifrance.fr/nos-appels-a-projets-concours/concours-dinnovation-i-lab)**——上限 60万€，覆盖研发费用最多60%（France 2030 旗舰项目），门槛是"公司成立<2年+已证明可行性"，现阶段太早，定为 6-12 个月后的目标。
4. 法兰西岛大区 Innov'up 等区域创新补贴可叠加，注意 de minimis 累计上限 30万€/3个财年。

### Track B — 房子走"公共利益合作"这条钱

1. **Bail emphytéotique administratif (BEA)**——市镇把地/房子长租给你（18-99年），租金("canon emphytéotique")通常象征性，条件是自己出钱盖/修，到期建筑归还市镇。配合前面已识别的 bien sans maître / abandon manifeste 废弃房产路径，理论上可以做到"房子几乎零成本拿到手，钱全砸在装修"。⚠️ 需核实：BEA 传统上更常见于公共利益/非营利主体，项目的法律实体形式(纯商业 SASU vs. 协会/SCIC)可能影响市镇是否愿意给这个条件——适合 9/15 当面问。
2. **CAF 投资补贴**（每名额7400-17000€，gros œuvre 工程加成）覆盖装修支出，废弃建筑翻新大概率吃满加成。
3. Module 5.2 已有的 **Angel Parent Equity** 模式——如果 BEA+CAF 后仍有缺口，靠未来家长共同出资补，同样不是创始人自掏腰包。

### 两条线怎么连起来

Track A 不是直接拿去做房产抵押（这条路走不通，两类风险/资产完全不同）——它产出的是**信誉和故事资本**：Station F 背书、French Tech 资助、未来可能的 i-Lab 奖项，这些让市镇更愿意给一个体面的 BEA 条件、CAF 更愿意把项目当成"值得支持的创新型托育项目"。两条线靠"故事+信誉"打通，不是靠现金流打通。

## 9. Path A vs Path B 成本对比 + 最终融资瀑布（2026-08-21 定案）

### 成本对比

买/租的决策不能只看地价，两条路装修工程量其实差不多大——正经买一栋普通 maison 照样要拆墙改布局，不存在"买现成的就不用大动"这回事，唯一的真实差异是**要不要持续交房租**。

| | Path A：闲置老宅（BEA） | Path B：租一个现成合规空间 |
|---|---|---|
| 地/房子成本 | ≈0€（BEA 象征性租金） | 0€（不买），但要长期交租 |
| 翻新成本（法国行情） | 重度翻新档 1,000-1,500€/㎡ × ~200㎡ ≈ **20万-30万€**（参考：Toulouse 一个真实微托改造案例总花费19.7万€ HT） | 轻度改造档 500-800€/㎡ × ~200㎡ ≈ **10万-16万€**（如果场地本身已合规） |
| CAF 补贴抵扣 | -8.9万至-20.4万€（12名额×7,400-17,000€，重度翻新大概率吃满 gros œuvre 加成） | 同样可申请，但加成幅度可能更低 |
| 持续房租 | ≈0€，永久 | Essonne均价约181€/㎡/年，Palaiseau市中心实际挂牌约208€/㎡/年 → 200㎡ 约**4万-5万€/年** |
| 5年总成本量级 | 一次性缺口 0-20万€，之后几乎零成本 | 装修缺口 + **5年租金20万-25万€**，钱花完不留任何资产 |

**结论：Path A 更便宜，且更符合"零氪金"逻辑（一次性缺口可以用非稀释性资金填平，之后不再有持续现金流压力）；Path B 唯一的潜在优势（更快开门）也不成立，因为两条路装修工程量相近。已选定 Path A。**

### 最终融资瀑布（缺口填补顺序）

1. **CAF 投资补贴** — 大头，不用还。
2. **France Active 担保公司贷款** — 缺口部分，公司借、公司还，**"Garantie Emploi"担保比例80%，上限5万€，明确不需要个人担保（sans prise de caution personnelle）**，风险不落到创始人个人身上。（普通 Bpifrance「Garantie Création」只担保60%，银行仍可能要求部分个人担保，不选这条。）
3. **家长天使"种子轮"（Angel Parent Equity，Module 5.2）** — 前两层填不满时，公司层面再融一轮。投资家长**只拿财务回报，不拿治理权**——尤其不能影响招生规模、人员配置这类跟儿童安全直接挂钩的决策，这条红线正式化后更要写清楚。
4. ~~个人贷款~~ — **基本移出瀑布**。创始人本人有稳定收入，但这份信用/借贷额度已经预留给另一项独立计划（投资房购置），不能挪用去填 crèche 的缺口——一旦为 crèche 借了个人债务，还不上不是"缺口没填平"这么简单，是会拖累投资房贷款审批、拖累个人信用记录的真实代价，而且个人债务不会随crèche项目调整方向而消失，直接违背"保留随时撤退自由"这个创始人最看重的原则。**如果前三层都填不满缺口，说明的是这个具体方案（这栋房子的翻新体量）本身超出现阶段能承受的范围，该重新考虑的是方案本身（比如换一栋工程量更小的候选房产），而不是加一层个人负债硬撑。**
